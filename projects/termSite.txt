type   = software

desc   = Ultimately, computer terminals are just a set of messages sent between user and computer. But, the hacker-esque blinking cursor scares most people. To help introduce people to unix command lines, I have developed this standalone AppImage that can allow users to feel like they are logging into a website to "chat" or "text" with a computer. Messages "sent" are just piped to stdin, and messages "received" are just piped from stdout. In this way, even though it still ultimately needs at least a willingness to learn command syntax, this app can make things much more accessible to those just getting into command lines for the first time. Also, I have begun rigorously testing the security of this app for what I hope are obvious reasons. Though I have already verified that it blocks connections from other machines, I want to test it a bit harder before declaring it out of alpha for security reasons.
